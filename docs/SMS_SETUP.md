# 手机号短信验证码登录 · 开通指引

网站已接入手机号验证码登录（腾讯云短信），代码已部署上线。当前只差腾讯云侧的配置。

## 你需要做的（约 15 分钟）

### 1. 开通腾讯云短信服务

1. 打开 https://console.cloud.tencent.com/smsv2 （用你的腾讯云账号登录，个人实名即可）
2. 若提示开通，点击**开通短信服务**（国内短信按条计费，约 ¥0.04/条，无月租）

### 2. 创建短信签名

1. 左侧菜单 **国内短信 → 签名管理 → 创建签名**
2. 签名内容建议与站点相关，如 **"周日服务"** 或 **"SSCN社区"**
3. 类型选 **App** 或 **公众号**，上传对应证明（个人可选公众号/小程序认证截图等）
4. 等待审核（通常几分钟到几小时）

### 3. 创建短信模板

1. 左侧菜单 **国内短信 → 正文模板管理 → 创建正文模板**
2. 模板内容填：
   ```
   您的验证码是{1}，{2}分钟内有效。如非本人操作请忽略。
   ```
3. 变量说明：`{1}` = 验证码（6 位数字），`{2}` = 有效期（分钟，固定填 5）
4. 申请类型选 **验证码**（审核最快）
5. 等待审核

### 4. 获取凭证

| 凭证 | 获取位置 | 示例 |
| --- | --- | --- |
| `TENCENT_SECRET_ID` | 访问 https://console.cloud.tencent.com/cam/capi 创建密钥 | `AKIDxxxxxxxx` |
| `TENCENT_SECRET_KEY` | 同上（创建时只显示一次，务必保存） | `xxxx` |
| `TENCENT_SMS_SDK_APP_ID` | 短信控制台 **应用管理 → 应用列表**（5 位数字） | `1400xxxxxx` |
| `TENCENT_SMS_SIGN_NAME` | 签名管理里已审核的签名 | `周日服务` |
| `TENCENT_SMS_TEMPLATE_ID` | 正文模板管理里已审核的模板 ID（数字） | `18xxxxx` |

### 5. 把凭证交给我

把上面 5 个值发给我，我会：
1. 通过 API 配置到 Cloudflare Worker 的环境变量（Secret 加密存储，不会出现在代码里）
2. 用你的手机号发一条真实验证码，端到端测试完整登录流程

## 常见问题

- **个人实名可以发短信吗？** 可以。但签名审核更严，建议用与个人真实身份相关的签名内容；发送量上限比企业低（一般足够社区使用）。
- **验证码有效期多久？** 5 分钟，同一手机号 60 秒内只能重发一次，最多 5 条未使用。
- **登录后会话多久过期？** 30 天，登出会清除。
- **没配好之前线上什么状态？** 登录页会显示"短信服务未配置"的提示，其他功能（浏览、资料库、展厅）不受影响。

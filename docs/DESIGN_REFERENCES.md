# 设计参考与使用边界

## 核心参考

- Ragged Edge：首页超大扩展黑体、极少信息、指针驱动的轻微文字位移。
- Shopify Design：大面积内容区块、滚动时明确的章节切换和强节奏。
- Recent Design：悬浮胶囊导航、编辑型留白、单色主视觉、图片与文字遮罩。
- Apple HIG 共通原则：层级清楚、动效克制、触控目标足够大、支持减少动态效果。

## 当前视觉系统

- 主色：墨黑、暖白。
- 强调色：酸性绿、钴蓝、橙红。
- 巨型英文标题使用 Archivo Black，它是对 Ragged Edge 扩展黑体气质的开源替代，不复制其商业字体。
- 中文正文使用系统中文无衬线字体，确保本地加载与可读性。
- 动效只服务于首屏反馈与链接提示，不使用滚动劫持。

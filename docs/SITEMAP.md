# Sunday Service CN 页面地图

## 当前页面

- `/` 首页
  - 巨型 Sunday Service CN 首屏
  - 最新讨论
  - 推荐课程
  - 本月展览
  - 人物资料摘录
- `/community` 社区
  - 成员发帖与媒体上传
  - 米白底双栏中型帖子流
- `/community/kendrick-ranking` 编辑样例详情
  - 正文
  - 回复区
- `/community/post/[id]` 数据库帖子详情与回复
- `/database` 资料库
  - 公开资料分类筛选
  - 成员提交入口
- `/exhibitions` 展厅入口
  - 本月展览
  - 筹备项目
  - 展览申请说明
- `/events` 活动
- `/about` 关于
- `/login`、`/register` 邮箱或手机号登录/注册入口；本地开发模式建立测试身份
- `/account` 账户与个人资料；上传头像、修改名称、用户名、手机号和个人简介
- `/submit/library` 提交资料
- `/submit/exhibition` 提交独立线上展览入口
- `/admin` 审核与管理后台

## 关键用户路径

1. 首页 → 最新讨论 → 帖子详情 → 回复。
2. 首页 → 资料库 → 分类 → 资料详情。
3. 首页 → 展厅 → 独立展览入口。
4. 社区 → 发帖 → 上传媒体 → 发布。
5. 用户提交展览 → 管理员审核 → 展厅入口公开。
6. 管理员 → 隐藏或恢复帖子/评论 → 导出 JSON 备份。
7. 登录/注册 → 输入邮箱或手机号 → 本地测试身份；正式环境接入邮箱或短信验证服务。
8. 账户 → 上传头像、修改名称与手机号 → 保存个人资料。

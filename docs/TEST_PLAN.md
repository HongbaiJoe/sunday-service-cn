# Sunday Service CN 功能版测试计划

## 本轮测试

- 首页在桌面与手机上完整显示，首屏只出现指定名称与说明文字。
- 主导航、账户、提交与后台页面可以访问。
- 游客看到登录提示；本地成员可以发帖、回复并更新个人资料。
- 本地邮箱/手机号入口可建立测试身份；头像、显示名称、用户名、简介与手机号可保存。
- 图片、视频与音频以分片方式上传，单文件不超过 25 MB。
- 社区桌面端为双栏中型彩色卡片，手机端为单栏，媒体不溢出圆角卡片。
- 社区、资料库、展厅与活动标题使用统一宋体艺术方向，长字不重叠。
- 资料与展览提交后进入待审核状态，审核通过后才公开。
- 管理员可以隐藏/恢复帖子和评论、停用/恢复成员、调整角色并导出备份。
- 所有本地图片加载成功且有替代文本。
- 所有页面在键盘操作下可访问链接、按钮、输入框和文本框。
- 开启系统“减少动态效果”后，页面不依赖动画才能阅读。
- 项目构建和现有自动测试通过。

## 自动检查

- `npm run lint`：TypeScript/React/Next.js 代码规范。
- `npm run typecheck`：TypeScript 类型完整性。
- `npm test`：生产构建、所有主要页面的服务端渲染、D1/R2 绑定、权限与分片上传源代码契约。
- 手动 API 冒烟：成员发帖/评论/提交、管理员审核、R2 小文件和大于 1 MB 文件的分片合并、备份导出。

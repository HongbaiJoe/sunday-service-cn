# Sunday Service CN 社区屏蔽词与内容审核规范

## 1. 目的

本文件定义 Sunday Service CN 社区平台的内容屏蔽词库与审核规则。所有用户生成内容（帖子、评论、资料提交、展览申请、用户名、头像描述等）在发布前必须经过屏蔽词过滤。

## 2. 处理等级

| 等级 | 标识 | 处理方式 |
|------|------|---------|
| P0 | 直接拦截 | 内容禁止发布，记录日志，严重者自动封禁账号 |
| P1 | 拦截并人工复审 | 内容暂存不公开，通知管理员审核后决定是否放行 |
| P2 | 警告并标记 | 内容可发布但标记为敏感，管理员可随时下架 |

## 3. 屏蔽词分类

---

### 3.1 种族歧视与民族仇恨（P0）

任何基于种族、肤色、民族、血统的歧视、侮辱或仇恨言论。

**关键词（部分列举，持续补充）：**

- 针对特定种族的贬称和侮辱性绰号（含中英文及谐音变体）
- 煽动种族优越/低劣论调的表述
- 基于肤色的侮辱性代称
- 针对特定民族（含少数民族）的歧视性称呼
- 否认特定种族屠杀历史的言论

**匹配规则：** 精确匹配 + 谐音变体（拼音替换、同音字、拆字）+ 英文等价词

---

### 3.2 政治敏感（P0）

违反中国法律法规的政治敏感内容。

**关键词（部分列举，持续补充）：**

- 涉及国家领导人及其家属的侮辱、造谣表述
- 煽动颠覆国家政权、推翻社会主义制度的言论
- 分裂国家、破坏国家统一的言论（含港独、台独、藏独、疆独等分裂势力相关标语和口号）
- 攻击中国政治制度、诋毁国家形象的恶意表述
- 涉及被依法取缔的非法组织的宣传内容
- 伪造或歪曲国家重大历史事件的不实信息
- 涉及国家主权和领土完整的不当表述（将台湾、香港、澳门称为"国家"等）

**匹配规则：** 精确匹配 + 变体（谐音、拆字、符号插入）+ 英文等价词

---

### 3.3 恐怖主义与极端主义（P0）

涉及恐怖主义、极端主义组织及其活动的宣传、招募、煽动内容。

**关键词（部分列举，持续补充）：**

- 国际公认恐怖组织的名称及别名
- 煽动实施恐怖袭击的言论
- 传播恐怖主义 ideology 和极端思想
- 招募恐怖组织成员的内容
- 宣扬暴力圣战、极端宗教主义
- 传授制造爆炸物、危险品方法的内容
- 恐怖组织旗帜、标志、口号的文字描述

**匹配规则：** 精确匹配 + 多语言变体

---

### 3.4 人身攻击与侮辱（P1）

针对个人的侮辱、谩骂、贬损、恶意攻击。

**关键词（部分列举，持续补充）：**

- 涉及家人的侮辱性称呼（及长辈的粗俗用语）
- 针对智力、外貌、身体缺陷的歧视性用语
- 贬低人格的粗俗词汇
- 人身威胁和暴力恐吓
- 恶意造谣和中伤
- 性骚扰性质的言语
- 基于职业的歧视性侮辱

**匹配规则：** 精确匹配 + 谐音变体 + 组合检测（主语 + 侮辱词）

---

### 3.5 色情低俗（P0/P1）

**P0（直接拦截）：**
- 招嫖、卖淫、色情交易相关表述
- 儿童色情相关内容（零容忍）
- 传播色情资源链接的表述
- 露骨的性行为描述

**P1（拦截并复审）：**
- 低俗擦边用语和隐晦色情暗示
- 不当性暗示和性骚扰言语
- 含性暗示的昵称和签名

**关键词（部分列举，持续补充）：**
- 色情交易术语及暗号
- 露骨身体部位的低俗代称
- 成人内容资源传播相关关键词
- 约炮、裸聊等 solicit 词汇

**匹配规则：** 精确匹配 + 拼音/谐音变体 + 上下文组合检测

---

### 3.6 暴力与血腥（P1）

宣扬暴力、展示血腥残忍内容、煽动自残自杀。

- 煽动自残、自杀的言论和方法描述

**匹配规则：** 精确匹配 + 上下文检测

### 3.7 违法犯罪（P0）

涉及违法犯罪活动的教唆、宣传、交易内容。

**子类及关键词：**

#### 3.7.1 毒品
- 毒品名称及俗称（冰毒、海洛因、大麻、K粉、摇头丸等）
- 毒品交易术语（出货、拿货、飞叶子等）
- 吸毒方法描述
- 美化吸毒的表述

#### 3.7.2 赌博
- 线上赌博平台名称及推广链接
- 赌博招揽用语（赌球、六合彩、时时彩等）
- 赌博术语中的交易暗号

#### 3.7.3 诈骗
- 诈骗手法关键词（刷单、杀猪盘、洗钱等）
- 钓鱼网站和虚假链接推广
- 虚假身份冒充表述

#### 3.7.4 违禁品交易
- 枪支弹药及零部件名称
- 管制刀具、武器交易
- 假证、假钞制作相关
- 盗窃、销赃相关术语

#### 3.7.5 黑客与网络犯罪
- 黑客攻击工具和方法教唆
- 窃取个人信息方法
- 网络攻击服务推广

**匹配规则：** 精确匹配 + 上下文组合检测 + 链接黑名单

### 3.12 隐私泄露与人肉搜索（P0）

未经同意公开他人隐私信息。

**检测规则：**
- 身份证号模式匹配（18位/15位身份证号正则）
- 手机号模式匹配（11位手机号正则）
- 银行卡号模式匹配
- 家庭住址 + 真实姓名组合
- "人肉"、"开盒"等搜索他人隐私的煽动性词汇
- 未经授权公开的私人照片/视频描述

**匹配规则：** 正则表达式模式匹配 + 关键词检测

### 3.13 网络暴力与集体骚扰（P1）

组织或参与针对特定用户的集体攻击。

- 持续骚扰特定用户的重复内容

**匹配规则：** 关键词 + 行为模式检测（短时间内针对同一用户的高频负面内容）

- 刷量、刷赞、买粉等灰产推广
- 与音乐社区主题完全无关的硬广

**匹配规则：** 关键词 + 链接域名检测 + 频率检测

---

### 3.15 未成年人保护（P0）

任何危害未成年人身心健康的内容。

**检测规则：**

- 引诱未成年人不良行为的内容
- 校园霸凌相关煽动性内容
- 未成年人隐私信息泄露

**匹配规则：** 上下文语义分析 + 关键词组合检测

在社区中推广盗版音乐资源或侵犯版权的内容。

**匹配规则：** 关键词 + 链接域名黑名单

### 3.17 自残与心理健康危机（P1）

涉及自残、自杀的表述需特殊处理。

**处理规则：**
- 检测到自残/自杀相关表述时，内容拦截不公开展示
- 自动向发布者推送心理援助热线信息
- 通知管理员人工跟进
- 不对发布者做惩罚处理，以关怀为主

**关键词（部分列举，持续补充）：**
- 自残、自杀方法的描述
- 表达轻生意愿的特定表述
- 鼓励他人自残的言论

## 4. 变体绕过检测

用户可能通过以下方式绕过屏蔽词，系统需同步检测：

| 绕过方式 | 示例 | 对策 |
|---------|------|------|
| 谐音替换 | 用同音字替代 | 建立谐音映射表 |
| 拼音输入 | 直接输入拼音 | 拼音关键词库 |
| 符号插入 | 在词中插入空格、星号等 | 去符号后再匹配 |
| 拆字 | 将字拆成偏旁部首 | 拆字还原映射 |
| 繁简混用 | 繁体字替代简体字 | 统一转简体后匹配 |
| 英文混写 | 用英文等价词替代 | 中英双语关键词库 |
| 表情符号 | 用 emoji 暗示敏感含义 | 敏感 emoji 映射表 |
| 零宽字符 | 插入不可见字符 | 去除零宽字符后匹配 |

## 5. 申诉机制

1. 被拦截内容的用户可在账户页面发起申诉。
2. 管理员在 48 小时内复审并给出处理结果。
3. 申诉通过的内容恢复展示，申诉未通过的告知原因。
4. 恶意申诉（频繁申诉已确认违规的内容）可导致申诉权限暂停。

## 6. 词库维护

- 词库文件存储于项目 `docs/MODERATION_WORDS.md`，同时维护一份机器可读的 JSON 配置（待实现）。
- 管理员可通过后台提交新增屏蔽词申请，需注明类别和等级。
- 每月审查一次词库，移除过时条目，补充新出现的变体。
- 重大社会事件期间可临时提升部分关键词的拦截等级。

## 7. 免责声明

本屏蔽词库仅用于保护社区环境和遵守法律法规，不用于监控用户正常交流。管理员在执行审核时应遵循比例原则，区分恶意违规与无心之失。艺术讨论中涉及社会议题的正常表达不构成违规。
